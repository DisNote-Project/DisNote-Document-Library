# 0.1.0

- Added the canonical DisNote document model, validation, deterministic JSON
  serialization and SHA-256 checksums.
- Added a responsive, localized and accessible native Flutter document reader.
- Added the secure React editor bridge for Flutter Web, Android and iOS.
- Added the typed NestJS document API client and portable HTTP transport.
- Added conflict-safe debounced document sessions with revision CAS and stable
  idempotency keys.
- Targeted Flutter 3.50 and migrated to the standalone `material_ui` package.
