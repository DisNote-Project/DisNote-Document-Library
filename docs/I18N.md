# Editor internationalization

DisNote bundles English and Vietnamese. Editor UI
messages are stored in the typed `EN_EDITOR_MESSAGES` and `VI_EDITOR_MESSAGES` catalogs. Editor components
resolve text by message key instead of embedding display strings directly.

This keeps the package consistent while allowing an application to supply its
own translations without changing library source.

## Default English UI

```tsx
import { DisNoteEditor } from "@disnote/core/editor/react";

<DisNoteEditor initialDocument={document} />;
```

English is used when `locale` and `messages` are omitted.

## Override messages

```tsx
import type { EditorMessageOverrides } from "@disnote/core/editor";
import { DisNoteEditor } from "@disnote/core/editor/react";

const messages: EditorMessageOverrides = {
  "toolbar.bold": "Strong",
  "math.category.structures": "Formula structures",
  "math.hint": "Select a slot, type a value, and press Tab to continue.",
};

<DisNoteEditor
  initialDocument={document}
  locale="en-custom"
  messages={messages}
/>;
```

Overrides are partial. Missing keys fall back to the selected vi/en catalog;
other locales use English. `locale="vi"` and `locale="vi-VN"` select Vietnamese.
The underlying BlockNote dictionary is selected at editor mount time. When changing
that vendor dictionary, remount with the current document rather than the original
document. Library-owned controls and read-only renderer labels accept locale props.

`MathEquationEditor` accepts the same `locale` and `messages` props when it is
used outside `DisNoteEditor`.

## Framework-neutral API

```ts
import {
  createI18n,
  defineEditorMessages,
  EN_EDITOR_MESSAGES,
} from "@disnote/core/editor";

const messages = defineEditorMessages({
  "link.apply": "Save link",
});

const i18n = createI18n({ locale: "en-custom", messages });
i18n.t("slash.results", { count: 3 }); // "3 results"
```

The public types are:

- `EditorMessageKey`: the exact union of supported keys.
- `EditorDictionary`: a complete dictionary.
- `EditorMessageOverrides`: a typed partial dictionary.
- `CreateI18nOptions`: locale metadata and overrides.
- `I18n`: the translator contract used by composable controls.

## Maintenance rule

When adding user-facing editor text:

1. Add corresponding entries to `EN_EDITOR_MESSAGES` and `VI_EDITOR_MESSAGES`.
2. Use `i18n.t("message.key")` in the component.
3. Add or update a test that renders or resolves the message.
4. Never concatenate translated sentence fragments; use placeholders such as
   `{{count}}` in a complete message.

Protocol values, persisted block types, LaTeX commands and document content are
not UI messages and must not be translated.
